Support

Start with the setup guide, or report a reproducible problem in the repository.

Installation and first use

The Quickstart walks through installation, loading the rules in a fresh session and checking the first result. The worked examples provide starter tasks.

Check your host app and version, the installed fabius release, the skills loaded in the current task and the tools it can access. Model access, connected services and their charges are managed separately through your chosen providers.

Report a bug or request a change

Search existing GitHub issues, then open an issue with the affected host and version, fabius release, steps to reproduce, expected result and actual result. Include a small example when possible.

Issues are public. Remove credentials, private project content and personal data before posting. A GitHub account is required to submit an issue.

Report a security problem privately

Use the repository’s private vulnerability reporting channel rather than a public issue. Read the security policy for scope and the reporting process.
