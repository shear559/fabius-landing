04 / THE METHOD

What guides the next step?

  • Effort. Stop when the next step is unlikely to improve the result.
  • Evidence. Use a test result or compiler error to guide a retry. Flag anything you couldn’t verify.
  • Memory. Retrieve the decisions and sources relevant to the task.

06 / GOOD QUESTIONS

Frequently asked.

How are skills activated?

Invoke Fabius or name a specialist. The router selects the skills the task needs. Your agent app controls which instructions load and which tools they can use.

Which models and apps can I use?

Use an instruction-following model in an app that can load Fabius. The compatibility record lists the host checks and their scope.

Are external tools included?

Fabius includes instructions, references and local helpers for scheduling, retrieval, design and verification. Your agent app connects any external services and enforces their permissions.

Can it remember my projects?

Archivum records approved decisions and sources. To recall them in a later session, your agent needs access to persistent project files, host memory or configured hooks.

What does the licence allow?

The source is public. The licence permits personal, non-commercial plugin use via the published marketplace command on machines you control. Modification, redistribution and commercial use require prior written permission. See terms and licence.
