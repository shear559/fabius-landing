What fabius adds

More ways to get the job done.

A model brings the intelligence. fabius adds specialist skills, repeatable workflows and a method for using the tools around it — from the first plan to the checked result.

Clearer execution.

Break the goal into the right steps, choose relevant skills and check the result before calling it done.

Wider capabilities.

Bring connected apps, media tools and data sources into the same task, with the workflow to use them.

Less repeated work.

Reuse approved project context and stop extra research or revisions when they no longer help the outcome.

The research behind the rules.

The routing rules document when more tools, planning or review are worth the effort. These diagrams illustrate three design principles; they are not measured performance curves.

The decision — is another step worth its cost?

Add a tool? Spawn a reviewer? Retry once more? The value gate asks whether the expected loss removed beats the extra cost. It guides optional effort alongside capability requirements, permissions and verification. The 22 core routing rules also include structural rules and operational heuristics; they are not all the same equation. Research stops when further evidence is unlikely to change the decision. A method you can inspect.

fabius documents how it chooses skills, tools and effort. Its research explains the assumptions behind 22 core routing rules; its benchmarks compare the same models with and without the layer. Published results include both improvements and regressions.

  • Climb one rung, stop at the knee. Under diminishing returns, add the smallest sufficient rung (inline → tool → retrieval → plan → subagent → swarm), never jump to a swarm.
  • Refine on a real signal. Use a test, compiler or other attributable signal to guide the next attempt. Retry caps are working budgets, not a guarantee of convergence; missing verification stays explicit.
  • Evidence with its limits. The July 1, 2026 quality panel reported improvements on three of four tested model tiers, with shorter output on all four. Results are specific to those tasks and models; the repository documents missing historical artifacts and replay limits.

Frequently asked.

What is fabius?

fabius is an installable AI skill layer: fifteen coordinated public skills that work above the model you already use. It adds planning, specialist workflows, tool selection, memory practices and verification. Install it in a compatible agent app, then use your chosen model and the tools available in that environment.

What does it actually improve?

fabius is designed to improve how the model approaches and completes a task: clearer scope, relevant specialist knowledge, purposeful tool use, fewer repeated steps and checks before delivery. It changes instructions, process and execution, without retraining the model or changing its weights. The results depend on the model, task and available tools.

Which models and apps can I use?

The rules are model-agnostic: they can be passed to an instruction-following model through a compatible host. The repository documents plugin installation for Claude Code, Codex and Grok Build, plus portable core instructions through AGENTS.md. Claude, GPT, Gemini and open models are examples. Full execution requires a host that can load the relevant skills and expose the necessary tools; a model name alone does not establish that support.

Can fabius create and combine videos?

It includes guidance for video production, including scripts, asset generation, editing and composition. With suitable tools available, the agent can turn a brief into a video workflow, use a connected generator, and combine clips, captions, sound and transitions through tools such as FFmpeg, Remotion or HyperFrames. The media tools are separate installations or services; fabius itself is not a video-generation model. Paid APIs require your own access and may add costs.

Are external tools included in the install?

The install includes the skill files and their reference material. External services are connected separately through your agent app, APIs, MCP servers or local tools. Media generation, live automations, external data and multi-model review need the relevant tools, permissions and sometimes paid accounts. The core planning and workflow guidance can be used without these connections.

How do I install it?

In Claude Code: /plugin marketplace add shear559/fabius, then /plugin install fabius@fabius, then /reload-plugins. For Codex and Grok Build, use the repository-documented steps in the install tabs. The Quickstart covers installation, session activation and a first-run check; the worked examples give you a task to try. Other compatible tools can load the portable AGENTS.md rules at the path they support. Check that your host has loaded the relevant skills and exposes the tools your task needs. A successful installation alone does not establish that every workflow has been tested.

Does it need a server or a new account?

The core skill layer runs inside your existing agent app and needs no separate fabius server or account. Your chosen model and any external tools handle their own processing and data access. The repository also includes an optional local Node runner for using the same rules through your own model API access.

Can it remember my projects?

The memory skill defines a project knowledge base, an index and an append-only log for approved decisions and sources. Cross-session recall requires persistent storage and the appropriate file access, host memory or configured hooks. It reuses relevant context when permitted, while allowing fresh-context review when that is needed.

Can it run without an agent app?

The repository includes an optional zero-dependency Node runner for the same rule files. It uses your own model access, and its boundaries are explicit: read-only until you pass --act, file tools check symlink-resolved paths against the working directory and block listed secret paths such as .ssh, .aws, .env and *.pem, and recognized destructive or publishing commands carry an additional approval hold. These checks are not an operating-system sandbox: approved programs can access resources with your user permissions. Prompts and selected observations are sent to your configured model provider. See runtime/README.md in the repository for current commands, supported execution paths and setup requirements.

Is it free? Is the source public?

The repository is public. Its LICENSE grants personal, non-commercial installation and use as an agent plugin through the published marketplace command, on machines you control. Redistribution, modification and commercial use are outside that grant and require prior written permission. Your model, API calls, connected services and computing resources may have separate costs. See Terms and licence for the source of these conditions.

How is the improvement evaluated?

The repository compares model-only runs with fabius-guided runs, including a generic concise-instruction control and a separate memory evaluation. Its dated results include gains, ties and regressions. In the July 1, 2026 four-model quality panel, three tiers improved and all four produced shorter output. Against the generic “be concise” control, the recorded quality scores favor fabius on Fable 5, Sonnet 5 and Opus 4.8, while their output is 20–34% shorter than the bare-model arm; Haiku 4.5 is the printed exception, where the control scores higher. BENCHMARKS.md distinguishes executed checks from model-graded scores and documents missing historical artifacts. These results do not guarantee improvement on every model or task.

Who chooses the tools and the amount of research?

You set the goal. fabius guides the model to identify the required capability, choose among tools actually available in the host, and spend more effort only when it is expected to help. Its workflow distinguishes reading, analysis, drafting, writing and execution; actions remain subject to your permissions and the controls of the environment.

Can it clean AI marks off my content?

For content you own, the repository includes guidance for removing specified invisible Unicode characters or file metadata using appropriate tools. This requires those tools and your authorization. It does not establish that content is human-written or guarantee that a watermark or AI detector will fail.
