    Frequently asked.

    What is fabius?

    Fabius is one set of rules above every model, organized into fifteen skills: a router, a lean core and thirteen specialists. It gives those skills distinct responsibilities and a shared workflow for planning, tool use, verification and approved project memory. Your chosen model executes through its agent app.

    What problem does the router address?

    A collection of skills can overlap, conflict or miss the task that needs them. The Fabius router is designed to classify the request, select relevant skills and compose their responsibilities. Shared rules have one owner, and specialist instructions refer to them. The host’s instruction hierarchy and controls remain authoritative.

    Does it automatically activate every skill?

    No. Installation and activation are separate. Invoke Fabius explicitly, or name the specialist you need, and check that the host loaded the relevant instructions. A task should use a relevant subset of the skills. The router supplies selection guidance; skill loading still depends on the agent app.

    How do different skills work together?

    A domain skill leads the subject of the work, while process skills guide planning, execution and verification. For a launch page, decor can lead the design, mercatus the copy, disciplina the implementation and checks, and archivum the approved project context. Parcus keeps the scope and effort proportional throughout.

    Which models and apps can I use?

    The repository documents installation for Claude Code, Codex and Grok Build. The rules can guide instruction-following models, including Claude, GPT, Gemini and open models, through a compatible host. The host must load the relevant instructions and expose the tools your task needs. Portable or standalone use outside the marketplace grant requires separate licence permission.

    Are external tools included?

    The package includes skill instructions, references and original local helpers for scheduling, retrieval, design and completion evidence. External services, model access and media tools are connected separately through your agent app. Some require their own accounts or usage fees. Actions remain subject to the host’s permissions and your authorization.

    How do I install and start?

    In Claude Code: /plugin marketplace add shear559/fabius, then /plugin install fabius@fabius, then /reload-plugins. Start a task with /fabius, or call a specialist such as /fabius:fabius-disciplina. For Codex and Grok Build, follow the install tabs, start a fresh session and name Fabius in your request. The Quickstart covers setup and the first-run check.

    Can it remember my projects?

    Archivum defines a project knowledge base, an index and an append-only log for approved decisions and sources. Cross-session recall requires persistent storage and appropriate file access, host memory or configured hooks. Fabius does not create persistent memory simply by being installed.

    What do the demos show?

    The four gallery demonstrations show visual mathematical reasoning, agent-team coordination, project memory and readable code. They include controls, walkthroughs, source and checks. The gallery uses local examples and resets when reopened. The separate homepage memory demo can save one note in your browser. None of these examples calls a live model or measures a model-quality gain.

    Is it free? Is the source public?

    The repository is public. Its LICENSE grants personal, non-commercial installation and use as an agent plugin through the published marketplace command, on machines you control. Redistribution, modification and commercial use are outside that grant and require prior written permission. Your model, API calls, connected services and computing resources may have separate costs.
