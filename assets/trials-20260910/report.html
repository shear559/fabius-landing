Constrained mathematics

  • Correctness ties in both repetitions. All four submissions satisfy the numerical probes and all eight reviewed proof criteria, including the constant-vertex interval and C1 behavior at the transitions.
  • Fabius took longer and emitted more output tokens in both math pairs: 353.080 s / 16,631 tokens versus 298.763 s / 15,120 in the first; 288.597 s / 14,650 versus 262.152 s / 12,959 in the second. These shared-environment timings describe the runs, not an isolated speed benchmark.
  • Different valid derivations reached the same answer. Extra instructions did not establish a correctness gain on this problem; longer proofs and floating-point last digits are not evidence of superiority. The next evaluation needs different problems and more repetitions before making a broader claim.

A complete landing page

  • All four landing pages pass the seven recorded groups, including the actual month/year labels, keyboard tabs, mobile menu and no-JavaScript content. Each produced a coherent fictional product page; the functional counts do not rank their visual quality.
  • The observed process adds context: the Fabius runs read the pinned design reference, and its second run measured a mobile overflow, changed the artwork container and retested. The baseline also planned, tested, revised presentation and checked keyboard behavior. More tool calls alone are not a benefit score.
  • The mobile captures reveal real tradeoffs. In the first pair, the Fabius page gives explanatory text more room but delays the product illustration; in the second pair, its long headline pushes the preview beyond the opening viewport, while the baseline shows more product. The next design check should examine what visitors actually see before scrolling.
  • Timing and output length change direction between repeats: the baseline is shorter/faster in the first pair, and Fabius is shorter/faster in the second. Two pairs on a shared environment do not establish a consistent speed or output-length effect.

A working task app

  • In the first pair, the Fabius application meets all 16 primary groups and the baseline meets 15. In the second pair, both meet 15. The confirmed miss in three of four artifacts is specific: after a pointer-opened dialog closes with Escape, WebKit leaves focus on the page body. Opening the same dialog by keyboard passes. This is one observed advantage in one pair, not a consistent win across both repetitions.
  • All four applications meet the primary storage, import validation, recovery and stale-write groups across the recorded browser configurations. These are meaningful local-app scenarios, including hostile text and corrupt storage; they are not a security certification or a guarantee about untested workflows.
  • The retrospective trace review shows planning, testing and correction in both conditions. It also records gaps, such as the second baseline run having no recorded full main-suite rerun after its later source edits. The independent grader evaluated the final immutable artifact in every case.
  • An additional exploratory probe found that a project literally named all collides with the project-filter sentinel in the first baseline app and the second Fabius app. The other two apps distinguish the project correctly. Stored data remains intact. This probe was added after initial outcomes, applied to all four artifacts and kept outside the primary scores. A follow-up brief should distinguish filter identity from a user-entered project name.
  • The mobile captures show that overview panels often push actual tasks below the opening viewport. The next design check should assess access to tasks and filters, alongside readable forms, recovery messages and empty states.
  • Fabius finished faster and emitted fewer output tokens in both recorded application pairs. Extra instruction and retrieval costs remain part of the treatment, and native input usage is available in each receipt. Two repetitions on a shared environment do not establish a general speed or cost advantage.

Limits

The control retains native Codex instructions. The treatment adds pinned Fabius contracts and reference resources. Elapsed time includes model calls and tools on a shared machine. Output tokens are reported by the CLI. This is not a calibrated visual-quality score or a general model-performance estimate.

These are twelve artifacts from one model and three deliberately detailed briefs. Repeated browser configurations and numerical probes are coverage, not additional independent model trials. Qualitative reviews are agent judgments. The study does not establish an aggregate improvement, a production-readiness guarantee or the effect on other models or less specified tasks. The measured Fabius snapshot remains 3.0.1; later changes cannot inherit these results.
