One notebook, three habits

Lattice is built around the way independent research actually happens: capture first, connect the evidence, then export what you need.

Capture without friction

Jot a note the moment an idea or observation appears. Every note is written straight to a plain file on your device — nothing waits on a network round trip before it's saved.

  • Notes are stored on your device, not on a remote server
  • Quick-capture works the same whether you're online or not
  • Optional local full-text search finds any note by content, not just title

Keep the source in view

Attach the source you were reading — a PDF, a URL, a dataset — directly alongside the note it produced, so the trail back to evidence is never lost.

  • Source links live beside each note, not in a separate app
  • Follow a note back to its origin at any time
  • Works with local files or web links

Export and reuse your structure

When it's time to write up, export any note or project to clean Markdown. Save a project's structure as a reusable template for the next one.

  • One-click Markdown export of a note or an entire project
  • Reusable project templates carry your structure forward
  • Exported files are plain text — readable in any editor

Three steps, start to finish

The same shape works for a week-long literature review or a year-long field study.

Frequently asked questions

Where are my notes actually stored?

On your own device. Lattice keeps your notes as local files rather than uploading them to a remote server.

Can I get my notes out in a plain format?

Yes. Any note or project can be exported to Markdown, which stays readable in any text editor, now or later.

How do I back up my notebook?

By exporting your files to a location you choose, such as an external drive or your own cloud folder. Lattice does not promise automatic cloud backup.

What happens to my files if I cancel?

Cancellation has no effect on files you've already exported — they're plain files on your device and remain exactly as they were.
