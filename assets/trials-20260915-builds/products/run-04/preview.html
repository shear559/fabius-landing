Explore the core loop

Three habits, one notebook: capture what you observe, connect it to where it came from, and export it whenever you need it elsewhere.

Capture without friction

Write notes in plain Markdown as you observe, read, or think. Every note is a file on your own device — nothing is queued for upload, and nothing waits on a network connection to save.

  • Offline by default, on any device you install it on
  • Reusable project templates for recurring study types
  • Notes open instantly because there is no round trip to a server

Keep the source next to the claim

Attach a source link — a file, a citation, a dataset — directly alongside the note it supports, so the evidence trail travels with your thinking instead of living in a separate tool.

  • Source chips sit inline with the note they back up
  • Optional local full-text search across notes and sources
  • Nothing is sent anywhere to resolve or preview a link

Export clean Markdown, any time

Turn a note, a project, or your whole notebook into plain Markdown files you fully own — ready to archive, back up, or move into any other tool.

  • One-click export for a single note or an entire project
  • Plain files, so backup is just copying them somewhere safe
  • No proprietary format to get locked into

A three-step workflow

Lattice follows the same loop every time, whether you're logging field data or reading a stack of papers.

  1. 01

    Capture the observation

    Start from a reusable project template and write the note in Markdown, right where the thought happens.

  2. 02

    Connect the source

    Link the file, dataset, or reference the note depends on, so the evidence stays attached instead of drifting away.

  3. 03

    Export when you're ready

    Pull a note, a project, or the whole notebook out as Markdown files whenever you need them somewhere else.

Frequently asked questions

Where is my data stored?

Everything you write in Lattice is stored locally on your own device. Notes, projects, and source links are never uploaded to a server as part of normal use.

Can I get my notes out in a standard format?

Yes. Any note or project can be exported as plain Markdown files at any time, so your writing stays readable outside Lattice.

How do I back up my notebook?

Back up by exporting your notes and projects to Markdown files and storing those files wherever you choose. Lattice does not promise automatic cloud backup.

What happens to my files if I cancel?

Cancelling only affects future billing. Any files you already exported remain exactly as they are on your device — cancellation does not remove or change them.
