Features

Three habits, one notebook

Everything below runs against notes stored on your own device.

Capture without leaving the page

Start a note anywhere in a project and Lattice saves it straight to your device — no sync step, no upload, no waiting on a network connection. Notes are plain text under the hood, so they stay readable even years from now.

  • Notes are stored locally on your device.
  • Quick-capture keeps your cursor in the note, not in a dialog box.
  • Every note belongs to a project, so nothing floats untitled for long.

Keep sources next to the claim

Attach a source link to any note as you write it, so the citation travels with the idea instead of living in a separate tab you'll lose track of. Reusable project templates give new research threads the same source-tracking structure from the first note.

  • Source links sit alongside each note, not in a separate bibliography file.
  • Reusable project templates carry your section structure into new notebooks.
  • Cross-links between notes stay intact when you rename a project.

Leave whenever you want

Export any note or an entire project as plain Markdown files. There's no proprietary format to get stuck in, and an optional local full-text search helps you find old notes before you decide what to export.

  • Markdown export for a single note or a whole project.
  • Optional local full-text search runs entirely on your device.
  • Exported files are yours to back up however you choose.

Workflow

A three-step rhythm

The same loop for a weekend project or a years-long research thread.

  1. 01

    Capture

    Jot a note the moment you find something worth keeping, right on the device you're using.

  2. 02

    Connect

    Link the note to its source and drop it into a reusable project template alongside related notes.

  3. 03

    Export

    When you're ready to write, publish, or archive, export the project as Markdown files you control.

FAQ

Before you ask

Where does Lattice store my notes?

On your own device. Notes are kept in local storage rather than on a remote server.

Can I get my notes out in a plain format?

Yes. Any note or project can be exported as Markdown files whenever you choose.

How do backups work?

Backups happen by exporting your files yourself. Lattice does not promise automatic cloud backup.

What happens to my work if I cancel?

Cancellation has no effect on files you've already exported — they stay yours, on your device.
