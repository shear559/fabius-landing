Local-first research notebook · fictional concept

Your research, held together — without leaving your device.

Lattice is a concept for independent researchers who want their notes, sources and drafts to stay on their own machine: capture ideas, connect them to sources, and export everything as plain Markdown whenever you like.

Feature exploration

Three habits, one notebook

Capture what you find, connect it to where it came from, and export it in a format you'll still be able to read in ten years.

Capture without friction

Jot a note the moment you find something worth keeping. Every note is saved to a plain file on your device, so it opens even when Lattice isn't running.

  • Quick-capture field for a fast, unstructured note
  • Tags stay attached to the note file itself
  • Nothing leaves your device to be saved

Connect notes to sources

Each note keeps a visible link back to where it came from, so a claim is never far from its citation when you revisit it later.

  • A source link sits alongside every note, not buried in metadata
  • Related notes can be linked to one another directly
  • Optional local full-text search across your own notes

Export as plain Markdown

A project, or a single note, exports to plain Markdown files whenever you want a copy — no proprietary format standing between you and your own work.

  • Markdown export preserves headings, links and tags
  • Exported files are yours to back up however you choose
  • Reusable project templates keep new exports consistently structured

Workflow

Three steps, start to finish

Lattice is built around one loop: capture a note, connect it while it's fresh, export when you're ready to share.

  1. 01

    Start from a template

    Begin a new project from a reusable template, so every literature review or field study starts with the same structure.

  2. 02

    Capture and link sources

    Add notes as you read, each one keeping its source link close by. Use local full-text search to find a note again later.

  3. 03

    Export to Markdown

    When a project is ready to share or archive, export it to plain Markdown files that stay readable outside of Lattice.

FAQ

A few likely questions

Where is my data stored?

Everything you write in Lattice is stored as files on your own device. This demonstration does not send notes anywhere.

Can I get my notes out in a plain format?

Yes. Any note or project can be exported to plain Markdown files, so your writing stays readable with or without Lattice.

How do backups work?

Backups happen by exporting your files to a location you choose, such as an external drive or your own cloud folder. Lattice does not promise automatic cloud backup.

What happens to my files if I cancel?

Cancelling has no effect on files you have already exported — they remain on your device exactly as exported.
