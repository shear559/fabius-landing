A fictional concept notebook

Research notes that stay on your machine — and never lose their source.

Lattice is a local-first notebook for independent researchers. Every note lives on your device, every claim keeps its source link, and every project can leave as plain Markdown whenever you want.

No account, no cloud sync, no data collection to demonstrate — this is a design concept, not shipping software.

Three things Lattice is built around

Capture without breaking flow

Jot the thought the moment it appears. Notes save instantly to this device — no account, no sign-in, no waiting on a network round-trip.

  • Notes are written straight to local storage on this device.
  • Works fully offline; there is nothing to sync before you can keep writing.
  • Reusable project templates start a new line of inquiry in one step.

Connect each note to its source

Attach the article, paper, or dataset behind a claim directly on the note that uses it, so the trail back to evidence never goes cold.

  • A source link sits alongside the note it supports, not in a separate tab.
  • Follow a claim back to where it came from in a single click.
  • Provenance travels with the note when you export or reuse it.

Leave whenever you want

Every note and every project can leave as plain Markdown, on demand — your files stay yours, in a format any editor can open.

  • Export a single note or an entire project to Markdown.
  • Reusable templates keep exported structure consistent across projects.
  • No proprietary format standing between you and your own research.

A three-step research loop

  1. 1

    Capture the thought

    Write the note the moment an idea appears. It's saved to this device immediately — nothing to configure first.

  2. 2

    Connect the source

    Attach the link, paper, or dataset behind the claim right on the note, so the evidence trail stays with the thought.

  3. 3

    Export and move on

    Pull a note or a whole project out as Markdown whenever you like, and carry it into whatever tool comes next.

Frequently asked questions

Where does my data live?

On this device, in local storage. Lattice is local-first: notes are not sent to a server as part of using the notebook.

Can I get my notes out in a normal format?

Yes. Any note or project can be exported to plain Markdown at any time, and read in any editor that opens text files.

How do backups work?

By exporting your files. There is no automatic cloud backup promised here — a backup is the Markdown export you keep somewhere of your choosing.

What happens to my work if I cancel?

Cancellation has no effect on files you have already exported. Anything you exported to Markdown stays exactly as it was, wherever you saved it.
