Local-first research notebook · fictional concept

Your research stays on your machine, in your words, with your sources.

Lattice is a fictional local-first notebook for independent researchers. Notes are stored on your device, every note can carry a source link, and everything you write exports cleanly to Markdown — no server required to keep working.

Everything happens next to your notes

Three ways Lattice keeps research self-contained, explained in the fictional demo below.

Capture on the device you're using

New notes are written straight to local storage on the device in front of you — there is no save-to-server step and no sign-in wall between you and a blank page. Start a note, keep typing, and Lattice keeps it where you made it.

  • Notes live on your device; nothing is required to leave it to keep working.
  • Start from a reusable project template (literature review, interview log, lab notebook) instead of a blank page.
  • Templates stay editable per project, so structure can adapt as the research does.

Keep every claim next to its source

Each note can carry a source link alongside the text it supports, so the citation travels with the idea instead of living in a separate reference manager you have to keep in sync by hand.

  • Attach a source link directly to the paragraph it backs up.
  • Source links stay visible in the note, not hidden in a footnote panel.
  • Move between a claim and its source without leaving the page you're writing.

Leave whenever you want, with everything intact

Any note or project can be exported to plain Markdown, and an optional local full-text search helps you find the right note first — searched entirely on-device, over notes already stored there.

  • Markdown export preserves headings, links, and source references as plain text.
  • Optional local full-text search runs over notes stored on the device — no note ever leaves it to be indexed.
  • Exported files are ordinary files: yours to move, back up, or open elsewhere.

A three-step workflow

How a single research thread moves through Lattice, from first note to finished export.

  1. 01

    Capture the note

    Open a project — or start one from a template — and write. The note saves to this device as you go.

  2. 02

    Connect the source

    Drop a source link next to the sentence it supports, so the citation and the claim stay together.

  3. 03

    Export or search

    Export the project to Markdown when it's ready, or use local full-text search to find it again first.

Frequently asked questions

Where does Lattice store my notes?

On the device you're using. In this fictional concept, notes are kept in local device storage rather than on a remote server.

Can I get my notes out in a plain format?

Yes — notes and projects can be exported to Markdown, a plain-text format you can open, edit, or move anywhere.

How do backups work?

By exporting your files yourself. This fictional concept does not promise automatic cloud backup — exporting to Markdown is the backup step.

What happens to my files if I cancel?

Nothing — cancellation has no effect on files you've already exported. Anything already saved to Markdown on your device stays exactly as it was.
