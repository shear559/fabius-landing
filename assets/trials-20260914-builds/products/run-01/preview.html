Research notes that stay on your machine, linked to where they came from.

Lattice is a sample concept for independent researchers: capture notes on your own device, keep every source attached, and export to plain Markdown whenever you like — no server required to read your own work.

One notebook, three everyday moves

Switch between the tabs to see how capturing, connecting and exporting fit together. Each tab holds different content.

Capture without losing your place

New notes open in a plain text editor that lives entirely on your device. Headings, lists and code blocks are written in Markdown as you type, so a note looks the same whether you view it in Lattice or in a plain text editor later.

  • Notes save to local files, not to a remote inbox.
  • Reusable project templates give a new note a starting structure — headings for a claim, evidence and open questions.
  • Nothing here requires a network connection to work.

Keep the source next to the claim

Every note can carry one or more source links — a paper, a page, a dataset — shown alongside the text instead of buried in a separate bibliography file.

  • Source links display next to the note they support, not in a detached reference list.
  • Linked notes form a small map of how ideas connect within one project.
  • An optional local full-text search looks across notes and their attached links on your device.

Leave whenever you want

A notebook is a folder of Markdown files on disk. Export turns any note, or an entire project, into plain .md files you can open, move, or hand to another tool.

  • Markdown export keeps headings, lists and source links intact as readable text.
  • Exported files are the backup: copy them anywhere you keep files today.
  • There is no lock-in format — what you exported stays yours to open with anything that reads Markdown.

A three-step workflow

The same shape for a short literature scan or a long-running project.

  1. 1

    Start from a template

    Pick a project template — literature review, methods log, or a blank notebook — so every new project starts with the same headings you already trust.

  2. 2

    Capture and attach sources

    Write notes as you read, attaching the source link to each claim so the evidence trail stays visible next to the note, not in a separate file.

  3. 3

    Export what you need

    When it's time to write up, draft, or move on, export the notes you need to Markdown and take them into any editor, manuscript tool, or archive.

Frequently asked questions

Where are my notes actually stored?

On your own device. Notes are kept as local files, not on a remote server operated by Lattice.

Can I get my notes out in a plain format?

Yes. Any note or project can be exported to Markdown, a plain-text format you can open in other editors.

How do backups work?

Backups are files you export yourself and store wherever you keep files today. Lattice does not promise an automatic cloud backup.

What happens to my notes if I cancel?

Cancelling has no effect on files you have already exported — those Markdown files remain yours on whatever device or drive you saved them to.
