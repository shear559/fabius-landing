Canvas `#F4F6F1`, sheets `#FFFFFF`, ink `#18271F`, secondary text `#59685D`, evergreen accent `#245F43`, pale chartreuse `#DDEA9D`, quiet green surface `#E7EDDE`. Functional controls use ink, white or evergreen. Chartreuse marks source atmosphere, never unrelated controls. No dark glow, randomized colors or autoplay.

Desktop proposition: 44px. Phone proposition: 36px. Notebook headings: 27–30px. Reading prose: 16px. Compact metadata: 11–13px. Structural spacing uses 8/12/16/24/32/40/48px. Sheets use 6–12px radii with a single restrained notebook shadow.

At phone width the note library becomes a horizontal row above the readable note; connection cards stack; the draft outline precedes the editor. Tabs remain visible and keyboard-operable. All content is visible without entrance animations. Reduced motion removes smooth scrolling.
