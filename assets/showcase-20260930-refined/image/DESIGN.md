# Pelagic visual system

Surface: an artwork gallery. The complete biological image is the primary content; controls support closer inspection and export.

The page uses self-hosted Rubik on a warm near-white canvas. Ink is deep desaturated teal, with one muted green interaction accent. The image carries the rich cyan, amber and marine colors. Shell controls remain quiet and consistent.

Desktop uses a wide 3:2 artwork next to a narrow editorial note column; mobile stacks the image before the notes. Three detail thumbnails below the canvas expose focal regions of the same image. There are no automatic image transitions. The zoom and pan state is explicit and Reset always restores the complete composition.

Source of tokens: `styles.css :root`. Structure: `index.html`. Interaction: `app.js`. Biological art, its full prompt and the image-generation receipt: `artwork/`. The generated master is shown on every normal first visit and needs no JavaScript to render.

Downloads always deliver the full master, not the current crop. The artwork is an imagined ecology; visual details do not establish scientific species identification or anatomical correctness.
