Checks and limits

The current browser record covers interactions, guided tours, downloads, media playback and responsive layout. It uses Chromium and WebKit on macOS at 390 and 1440 CSS pixels. Mobile emulation is not a physical phone test. Browser console and HTTP failures are checked separately from visual review.

  • Sentinel’s executable checks cover deny precedence, malformed inputs, simultaneous barriers, tenant isolation and minimal counterfactuals.
  • Relay’s executable checks cover ambiguous commit, lease expiry, monotonic fencing tokens, late stale writes, retry reconciliation and unique output.
  • Cohort’s executable checks cover dependency gating, concurrency, artifact validation, failed-task isolation, retry and release conditions.
  • Model checks verify the declared rules of these fixtures. They are not production-security assurances, deployment evidence or quality scores.
