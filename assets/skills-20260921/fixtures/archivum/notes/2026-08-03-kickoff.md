# Harbor — kickoff, 2026-08-03

Attendees: Noa (product), Eitan (backend), Maya (mobile), Liam (design)

Harbor is a mobile app for small marinas: berth bookings, arrivals board, and a harbormaster chat.

Decisions
- We build iOS first; Android follows after the iOS launch.
- Backend: Postgres on the managed cloud database, one instance per region.
- Design system: Liam owns it; first screens by 2026-08-20.

Open
- Payment provider not chosen.
- Do we need offline mode for harbormasters on the dock? Maya to research.
