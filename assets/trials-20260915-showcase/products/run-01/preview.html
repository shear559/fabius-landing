Features

Three moves, one notebook

Every research session is some mix of capturing, connecting, and exporting. Lattice keeps all three close together.

Capture without leaving the page

Select a passage from an article, PDF, or dataset and save it as a note. The source link travels with it automatically, so you always know where an idea came from.

  • Source links attached to every note
  • Quick tagging while the context is fresh
  • Everything saved to local device storage

See how your notes relate

Link related notes and sources into a working map of your project. Backlinks make it easy to notice patterns across sources you captured weeks apart.

  • Two-way links between notes
  • Optional local full-text search across your notebook
  • A map view for spotting overlooked connections

Take your work with you

Export any note, or a whole project, as clean Markdown files ready for a paper draft, a static site, or another tool entirely. Nothing is locked in.

  • Markdown export for notes and projects
  • Reusable project templates for recurring research formats
  • Exported files are yours to back up however you like

FAQ

Good questions

Where are my notes stored?

Everything you capture in Lattice is stored on your own device. This is a local-first concept: your notebook lives with you, not on a remote server.

Can I get my notes out of Lattice?

Yes. Any note or project can be exported as Markdown, a plain, portable file format you can open in almost any editor or publishing tool.

How do I back up my research?

Back up by exporting your files to wherever you keep backups — an external drive, your own sync tool, and so on. Lattice does not promise automatic cloud backup.

What happens if I cancel?

Cancelling has no effect on files you've already exported. Those Markdown files are yours to keep and use, independent of any subscription.
