Features

Three moves cover a research session

Lattice keeps the everyday loop of independent research small: write it down, tie it to where it came from, then take it wherever you're publishing.

Write the moment you notice something

A note starts as plain text, right where you're already working. There's no server round-trip and no sign-in gate between an idea and it being saved to your device.

  • Notes are plain Markdown files stored locally.
  • Reusable project templates give a new notebook a starting shape.
  • Tag as you type — tags stay attached to the file, not a database.

#fieldnotes template: survey

Keep the source right beside the claim

Every note can carry the source it came from, plus links to other notes that reference the same idea — so six months later you can still see why you wrote it.

  • Source links sit alongside the note, not in a separate app.
  • Backlinks surface every note that points to the one you're reading.
  • Optional local full-text search finds related notes by wording, not just tags.

Leave whenever you want

A notebook, a project, or a single note exports to clean Markdown with its source links intact — so the files you write stay useful outside Lattice.

  • One note or a whole project exports as Markdown.
  • Source links are preserved in the exported files.
  • Exported files double as your own backup copy.

FAQ

Good to know

Where are my notes actually stored?

On your own device, as local files. Lattice is built around local device storage rather than a remote database, so your notebook works the same with or without a network connection.

Can I get my notes out in a plain format?

Yes. Any note, project, or full notebook can be exported as Markdown, which stays readable in any text editor or another notebook tool.

Does Lattice back up my notebook automatically?

Not automatically. Backups happen by exporting your files to wherever you keep backups — there is no automatic cloud backup promised as part of this fictional plan.

What happens to my files if I cancel?

Cancelling has no effect on files you've already exported — they're plain Markdown on your device and stay exactly as they were.
