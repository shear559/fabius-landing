Features

Three habits, one notebook.

Lattice is built around how independent research actually happens: quick capture, deliberate connection, and an export you fully own.

Capture stays out of your way

Start a note from anywhere in the app in under a second. Every note is written straight to a plain-text file on your device — nothing waits on a server round-trip.

  • Notes save as Markdown files on your device as you type.
  • Reusable project templates set up headings, tags and source slots in one step.
  • Attach a source link to a note the moment you capture it.
source: field-notes-03.md

See how your notes actually relate

Lattice keeps a local map of the links between notes and sources, so a thread of reasoning stays visible instead of buried in folders.

  • Backlinks appear automatically wherever a note is referenced.
  • Source links travel with a note when it's connected to others.
  • Local full-text search finds a note by its content, not just its title.

Leave whenever you want

Every note is already a plain Markdown file, so exporting a single note, a project, or your entire notebook produces files you can open anywhere.

  • Export a note, a project, or the full notebook as Markdown.
  • Source links are preserved as plain Markdown references.
  • Exported files are your backup — Lattice does not promise automatic cloud backup.

Workflow

From a loose thought to a finished file, in three steps.

  1. 01

    Capture

    Write the note where the thought happens. It's saved to your device as a Markdown file immediately, with a template ready if the project calls for one.

  2. 02

    Connect

    Link the note to its sources and to related notes. Search locally across everything you've written to find the thread again later.

  3. 03

    Export

    Turn a note, a project, or the whole notebook into Markdown files whenever you need them elsewhere — no lock-in, no conversion step.

Frequently asked

Before you ask support (there is none — this is a demo)

Where are my notes actually stored?

On your own device. In this concept, Lattice does not require an account or a server to write, edit, or read a note — the files live in your local notebook folder.

Can I get my notes out in a format I control?

Yes. Every note exports as plain Markdown, individually or as a full notebook, so the files stay readable with or without Lattice installed.

Does Lattice back my notes up automatically?

No automatic cloud backup is promised. Backing up means exporting your files to storage you choose — a drive, a folder you sync yourself, or anywhere else you trust.

What happens to my files if I cancel?

Nothing. Cancellation has no effect on files you've already exported — they're already on your device and remain fully yours.
