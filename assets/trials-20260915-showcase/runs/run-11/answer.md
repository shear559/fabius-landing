All three deliverables are complete in this directory:

- **`solution.md`** — compact exact answer table (6 regimes A–F covering $t\in[-2,4]$), the geometric reduction to a strictly-convex 2D QP on a pentagon (after eliminating $z$), full KKT proof with an explicit sign convention (3D multipliers $\nu,\lambda_1,\dots,\lambda_5$, solved exactly per regime), proof that no vertex/edge/interval was missed (exhaustive face enumeration + the three non-candidate vertices shown to always violate a multiplier sign), continuity/$C^1$-ness of the value function via an envelope-theorem identity, and a plain-language walkthrough of each transition.
- **`solution.py`** — stdlib-only (`fractions`), `solve(t)` returns exact-derived `x,y,z,value` as floats plus `regime`/`active` metadata; raises on out-of-range/non-numeric `t`; importing it produces no output.
- **`verification.md`** — records the sympy algebra/KKT checks and two independent numerical oracles (scipy SLSQP black-box on the original 3-var problem, and a from-scratch stdlib-only finite-candidate polygon oracle) cross-checked against `solution.py` over 284 points including every regime boundary straddled at ±1e-6; max discrepancies were ~1e-13–1e-8 (solver/search noise). `verify.py` is the runnable script (`python3 verify.py`), which degrades gracefully without scipy.
- **`diagram.svg`** — self-contained (no external resources), responsive pentagon-and-optimizer-path diagram; visually confirmed clean and legible at both 375px mobile width and desktop width via headless Chromium/Playwright, with exact-fraction vertex labels, a regime legend, and edge-constraint labels.
