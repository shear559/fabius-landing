Built the Lattice landing page (`index.html`, `styles.css`, `app.js`) with an editorial paper-and-terracotta visual identity, an original SVG icon family, and a hero illustration that doubles as the required play/pause/restart workflow demo (capture → connect → export). All required test seams — mobile nav, feature tabs, billing toggle, FAQ details, primary CTA — were verified via a headless Playwright script (interactions, ARIA states, no-JS fallback, 360px/1440px screenshots, zero console errors), then the throwaway test script and screenshots were deleted. `README.md` documents run instructions, design decisions, and exactly what was checked.
