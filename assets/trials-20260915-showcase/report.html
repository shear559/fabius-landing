New product demonstrations · paired results

September 15, 2026. Twelve new independent generations on three enriched briefs: two run pairs for each task. No generated product was repaired after the run or selected because it looked better. The original functional oracle and its results are retained. The full app suite was rechecked symmetrically on all four applications after correcting wording and reset-confirmation recognition; the table includes those corrected observations.

The new briefs request richer product demonstrations, a Board/List view and an original geometric diagram. Both conditions receive the same task brief. These additions improve what can be inspected, but the existing functional checks do not grade every new visual request. Visual differences are visible in the actual products; the check counts are not design scores.
