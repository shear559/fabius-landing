FABIUS / DEMONSTRATIONS / SEPTEMBER 21–22, 2026

A film, an image, a study.
Inspect the evidence.

These three products were built with Fabius over several refinement passes. They illustrate the workflow; they are not a controlled estimate of the plugin’s effect.

How they were made

Each product was built in a fresh headless Claude Code 2.1.275 session running claude-opus-5 with only the Fabius 3.2.0 plugin loaded: no user settings, no MCP servers and no web access. The session received a written brief and a folder of inputs, and the brief named the Fabius skill that owns the work (fabius-decor for the film and the image, fabius-scientia for the study). Two more sessions of the same kind then refined each product: the first from browser testing and a design read, the second from an independent review of the live pages. The notes for the study never mentioned the hidden answer used to score it.

The product files are published as those sessions left them. Outside the sessions we added only the preview wrapper that drives the guided tour, and we packaged the downloads.

RNA-seq study11 / 11 calls correct · 0 falseThe data are synthetic: 2,000 genes, 3 control and 3 treated samples, and 60 responders that we planted. The planted list was never shown to either session. At 5 % FDR the analysis called 11 genes. All 11 are planted responders, each with the right direction, so it found 11 of the 60 (18 %). The explorer itself explains why the calibrated test is conservative with three replicates. The analysis reruns byte for byte.
Browser checks3 products · 2 enginesWe loaded each product in Chromium and WebKit at 390 and 1280 CSS pixels (and at 1280 with reduced motion), under the same security policy the gallery uses. There were no console, policy or request errors; for the film, only the normal aborted range requests of video loading. There was no horizontal overflow, every tour step exists and works, and focus stays visible across the first twelve tab stops.

These counts measure specified requirements. They are not aesthetic scores, user satisfaction measurements or evidence of a universal gain. Browser automation used Chromium and Playwright WebKit on an Intel Mac; no physical phone was tested.

Limits

The film brief asked for 20 to 30 seconds. The refinement lengthened the film to 39.5 seconds so that every line stays on screen long enough to read. The study’s data are simulated, so its genes are anonymous and carry no biological meaning. A fourth build, a security review, did not finish and is not published.
