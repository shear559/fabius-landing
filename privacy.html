Privacy

This page describes the website’s own code. Hosting, GitHub and the model or tools you choose have separate practices.

This website

The site has no forms, account sign-in or client-side analytics. Its page scripts do not set cookies or store visitor data in local storage. Fonts and page assets are served from this site’s origin.

Copy buttons write the displayed commands to your clipboard only when you activate them. They do not read your clipboard. If automatic copying is unavailable or rejected, the page displays and selects those commands for manual copying.

Hosting and external links

Vercel hosts this website and handles requests needed to deliver it. Hosting-provider request processing and logs are separate from the page’s JavaScript. This page does not specify or control the provider’s retention, security or operational practices.

Following a GitHub link takes you to GitHub, where its own account, issue and privacy practices apply. Public issues are visible to other people. Use the private vulnerability channel for security reports.

Using Fabius

Installing fabius adds instructions to your chosen agent environment. This website does not receive the tasks you run there. Your agent app, model provider and connected tools may process prompts, selected files and tool results according to their settings and terms.

The optional local runner sends prompts and selected observations to the model provider you configure. Project memory requires storage and access that you authorize. Review the relevant host, runtime and provider settings before using private material.

Questions or corrections

Use the support channels for a question about this site’s behavior. Do not include sensitive information in a public issue.
